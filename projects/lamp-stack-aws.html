Project Overview

This project involved deploying and configuring a complete LAMP (Linux, Apache, MySQL, PHP) stack on Amazon EC2 to host web applications in a cloud environment. The deployment process included server configuration, web server setup, database installation, PHP integration, and infrastructure automation.

To improve efficiency and consistency, shell scripts and AWS CLI tools were used to automate server provisioning and deployment tasks. This automation reduced setup time by approximately 40% while ensuring that environments could be recreated reliably across multiple deployments.

Deployment Workflow

1 AWS EC2 Provisioning

Launched and configured an EC2 instance to serve as the foundation of the cloud-hosted web environment. 

aws ec2 run-instances \
--image-id ami-xxxxxxxx \
--instance-type t2.micro
  • Configured EC2 resources
  • Established security groups
  • Managed SSH access
  • Configured networking
2 Linux Server Configuration

Prepared the Linux operating system environment and updated required system packages. 

sudo apt update
sudo apt upgrade -y
  • Updated system packages
  • Configured server environment
  • Managed user permissions
  • Improved system security
3 Apache Web Server Setup

Installed and configured Apache to host and serve web applications. 

sudo apt install apache2 -y

sudo systemctl start apache2
sudo systemctl enable apache2
  • Installed Apache
  • Configured virtual hosts
  • Enabled web services
  • Verified HTTP connectivity
4 MySQL Database Configuration

Installed and secured MySQL to support dynamic web applications. 

sudo apt install mysql-server -y

sudo mysql_secure_installation
  • Configured database services
  • Created databases and users
  • Applied security settings
  • Validated connectivity
5 PHP Integration & Automation

Installed PHP and automated deployment tasks using shell scripts and AWS CLI tools. 

#!/bin/bash

sudo apt install php php-mysql -y

sudo systemctl restart apache2
  • Integrated PHP with Apache
  • Created automation scripts
  • Automated deployments
  • Reduced setup time by 40%
