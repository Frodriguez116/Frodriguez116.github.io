Project Overview

This project involved deploying and configuring a complete LAMP (Linux, Apache, MySQL, PHP) stack on Amazon EC2 to host dynamic web applications in a cloud environment.

To improve deployment efficiency and consistency, shell scripts and AWS CLI commands were used to automate server provisioning and software installation. These automations reduced setup time by approximately 40% while ensuring reliable environment replication.

Project Objectives

  • Deploy a production-ready LAMP environment
  • Configure AWS cloud infrastructure
  • Automate deployment workflows
  • Improve consistency across environments
  • Reduce manual server configuration
  • Demonstrate cloud administration skills

Deployment Workflow

1 AWS EC2 Provisioning

Launched and configured Amazon EC2 instances to provide cloud-based infrastructure for the LAMP stack. 

aws ec2 run-instances
--instance-type t2.micro
  • Provisioned EC2 resources
  • Configured networking
  • Established SSH access
  • Configured security groups
2 Linux Configuration

Prepared the Linux operating system and installed required packages and updates. 

sudo apt update
sudo apt upgrade -y
  • Updated packages
  • Configured server environment
  • Managed permissions
  • Improved security
3 Apache Web Server Deployment

Installed and configured Apache to host web applications and serve HTTP traffic. 

sudo apt install apache2

sudo systemctl start apache2
  • Installed Apache
  • Configured web services
  • Enabled automatic startup
  • Validated connectivity
4 Database Configuration

Installed and secured MySQL databases for dynamic application support. 

sudo apt install mysql-server

sudo mysql_secure_installation
  • Configured MySQL
  • Created databases
  • Created user accounts
  • Applied security settings
5 Automation & Deployment

Automated provisioning and deployment processes using shell scripts and AWS CLI. 

#!/bin/bash

sudo apt install php php-mysql -y

sudo systemctl restart apache2
  • Automated installations
  • Reduced setup time by 40%
  • Created repeatable deployments
  • Improved infrastructure consistency
