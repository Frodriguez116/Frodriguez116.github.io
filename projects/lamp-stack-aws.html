LAMP Stack Deployment on AWS EC2

Cloud Infrastructure Deployment & Automation Using AWS

Project Type

Cloud Infrastructure / Backend Deployment

Technologies

AWS EC2, Linux, Apache, MySQL, PHP

Automation

Shell Scripting, AWS CLI

Deployment

Scalable Web Hosting Environment

System Overview

Designed and deployed a full LAMP (Linux, Apache, MySQL, PHP) stack on Amazon EC2 to host dynamic web applications. The system focuses on cloud-based infrastructure setup, automation of deployment processes, and scalable server configuration.

Cloud Infrastructure Setup

EC2 Instance Provisioning

Configured Amazon EC2 instances to host Linux-based server environments, enabling scalable and reliable cloud deployment for web applications.

LAMP Stack Installation

Installed and configured Linux, Apache, MySQL, and PHP to establish a full backend web hosting environment capable of serving dynamic applications.

Server Configuration & Security

Configured firewall rules, security groups, and permissions to ensure secure access to deployed applications while maintaining system stability.

Automation with AWS CLI & Shell Scripts

Automated server provisioning and setup using shell scripts and AWS CLI commands, reducing manual deployment time and improving consistency across environments.

Deployment Highlights

Automated Provisioning Script
sudo apt update -y sudo apt install apache2 -y sudo apt install mysql-server -y sudo apt install php libapache2-mod-php php-mysql -y
AWS CLI Instance Launch
aws ec2 run-instances \ --image-id ami-0abcdef1234567890 \ --count 1 \ --instance-type t2.micro \ --key-name MyKeyPair \ --security-groups MySecurityGroup
