Robyn Framework Dependency Injection System

Advanced Application, Router, and WebSocket Dependency Injection Architecture

Project Type

Backend Framework Feature Design

Framework

Robyn (Python Async Web Framework)

Core Feature

Dependency Injection System

Scope

HTTP Routes + WebSockets

System Overview

Designed and implemented a multi-level dependency injection system for the Robyn framework, enabling Application-level, Router-level, and WebSocket-level dependency injection. This system allows shared resources such as loggers, caches, and configurations to be injected dynamically and accessed across HTTP routes and WebSocket connections.

Dependency Injection Architecture

Application-Level Dependency Injection

Global dependencies are injected at the application level and made available to all routes. These dependencies persist across the entire lifecycle of the application.

Use Case: Logging, configuration, shared services
from robyn import Robyn app = Robyn(__file__) GLOBAL_DEPENDENCY = "GLOBAL DEPENDENCY" app.inject_global(GLOBAL_DEPENDENCY=GLOBAL_DEPENDENCY) @app.get("/sync/global_di") def sync_global_di(request, global_dependencies): return global_dependencies["GLOBAL_DEPENDENCY"]

Router-Level Dependency Injection

Router-level dependencies are scoped to specific routers and available to all routes within that router. This allows modular dependency management.

Use Case: Feature-specific services, module-scoped caches
from robyn import Robyn, Request app = Robyn(__file__) ROUTER_DEPENDENCY = "ROUTER DEPENDENCY" app.inject(ROUTER_DEPENDENCY=ROUTER_DEPENDENCY) @app.get("/sync/router_di") def sync_router_di(request: Request, router_dependencies): return router_dependencies["ROUTER_DEPENDENCY"]

WebSocket Dependency Injection

WebSocket handlers support both global and router dependencies, enabling shared state management for real-time communication systems such as chat applications.

Use Case: Real-time messaging, caching, connection tracking
from robyn import Robyn import logging app = Robyn(__file__) app.inject_global(logger=logging.getLogger(__name__)) app.inject(cache=RedisCache()) @app.websocket("/chat") async def chat(websocket, global_dependencies=None, router_dependencies=None): logger = global_dependencies.get("logger") cache = router_dependencies.get("cache") logger.info(f"New connection: {websocket.id}") while True: message = await websocket.receive_text() cache.set(f"ws_{websocket.id}", message) await websocket.broadcast(f"User {websocket.id}: {message}")

Key Design Principles

Separation of Concerns

Dependencies are scoped at different levels (application, router, WebSocket), ensuring clean separation between global and feature-specific services.

Scalability

The DI system supports scalable backend architectures by allowing modular injection of services without tight coupling between components.

Real-Time Support

WebSocket integration ensures dependency injection works seamlessly in both HTTP and real-time communication layers.
